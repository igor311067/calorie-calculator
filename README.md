# Калькулятор калорий и меню на неделю

Статический сайт: один файл `index.html`, без сервера, без базы данных и без сборки.

Что внутри: расчёт нормы калорий и БЖУ (формула Миффлина-Сан Жеора), меню на 7 дней с учётом ограничений, квиз, скачивание меню.

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | Весь сайт (HTML, CSS, JS) |
| `netlify.toml` | Настройки Netlify (папка публикации, заголовки безопасности) |
| `.gitignore` | Что не отправлять в Git |

## Размещение на GitHub

**Через браузер:**
1. На github.com нажмите **New repository**, задайте имя (например, `calorie-calculator`), создайте.
2. Нажмите **uploading an existing file** и перетащите содержимое этой папки (сами файлы, не папку целиком).
3. Нажмите **Commit changes**.

**Через терминал:**
```bash
cd calorie-calculator
git init
git add .
git commit -m "Первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/calorie-calculator.git
git push -u origin main
```

## Размещение на Netlify

**Вариант 1. Из GitHub (рекомендуется, обновляется автоматически):**
1. Зайдите на app.netlify.com → **Add new site** → **Import an existing project**.
2. Выберите **GitHub** и разрешите доступ к репозиторию.
3. Выберите репозиторий `calorie-calculator`.
4. Поля **Build command** оставьте пустым, **Publish directory** — `.` (уже задано в `netlify.toml`).
5. Нажмите **Deploy**. Через минуту сайт будет доступен по адресу вида `https://имя.netlify.app`.

После этого каждое изменение `index.html` в GitHub само публикуется на сайт.

**Вариант 2. Без GitHub:** на app.netlify.com откройте **Sites** и перетащите папку `calorie-calculator` в область **Drag and drop**.

## Заметка про кнопки «Скопировать» и «Сохранить»

Копирование в буфер обмена работает только на защищённом адресе (HTTPS). На Netlify оно будет работать. Если открывать `index.html` двойным кликом с компьютера (`file://`), браузер может его блокировать.

## Где менять ссылки

В `index.html` найдите кнопки мессенджеров в конце квиза (поиск по `contact-btn`): там лежат ссылки на Telegram и MAX.
